# Archive — pre-product history

These documents describe earlier AnyRB versions (v0.3–v0.7): a bracket/lattice
reliability studio that was replaced by the current product on Oct 31, 2026.
They are kept so the project's development can be followed, and they are the
only place their claims apply.

**Nothing in this folder describes, validates, or is claimed for the current
app.** The current product is documented in the repository `README.md`,
specified in `V0_8_SPEC.md`, and mapped to its hackathon commits in
`HACKATHON_WORK.md`. The historical code that matches these documents lives in
`engine/`, `validation/`, `audit/`, `reports/`, `design/` and `history/`; the
submission packaging script (`scripts/package_submission.sh`) excludes all of
it from the clean submission tree.

| File | What it was |
|---|---|
| `PRODUCT_SPEC.md`, `PRODUCT_V2.md` | Product definitions for the retired bracket studio |
| `REPORT.md` | Research/validation report behind the retired engine |
| `REVIEW_RESPONSE.md` | Point-by-point response to the v0.3 review |
| `V0_3_SPEC.md` … `V0_7_SPEC.md` | Version specs for the retired line (current spec: `V0_8_SPEC.md` at the root) |
